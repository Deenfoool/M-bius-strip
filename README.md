# MÖBIUS

Интерактивная 3D-модель ленты Мёбиуса: свободное вращение, масштабирование, перенос камеры и управление касаниями. Лента построена по стандартной параметризации с полуповоротом на 180°, одной стороной и одним непрерывным краем.

## Управление

| Действие | Мышь / клавиатура | Сенсорный экран |
| --- | --- | --- |
| Вращение | ЛКМ и перетаскивание / стрелки | Один палец |
| Масштаб | Колесо / кнопки + и − | Разведение двух пальцев |
| Перенос | ПКМ и перетаскивание | Перемещение двух пальцев |
| Наклон камеры вокруг оси обзора | Q / E | Свободное вращение жестом |
| Исходный ракурс | Кнопка сброса / R | Кнопка сброса |
| Автовращение | Переключатель / пробел | Переключатель |

Горячие клавиши работают, когда область модели в фокусе. Ширина меняется без изменения топологии. Сетка показывает координатные линии, а подсветка края выделяет одну замкнутую кривую.

## Публикация

Полностью статический сайт без сборки, сервера и внешних CDN. Для GitHub Pages выберите **Settings → Pages → Deploy from a branch → main → / (root)**. Репозиторий не использует пользовательские GitHub Actions workflows.

После включения Pages адрес сайта: https://deenfoool.github.io/M-bius-strip/

Для локального просмотра запустите `python3 -m http.server 8000` в корне репозитория и откройте http://localhost:8000/. Для ES-модулей нужен HTTP, открытие `index.html` через `file://` не подходит.

## Геометрия и проверка

Использована параметризация:

```text
x = (R + v cos(u/2)) cos(u)
y = v sin(u/2)
z = (R + v cos(u/2)) sin(u)
u ∈ [0, 2π], v ∈ [-w/2, w/2]
```

`(2π, v)` отождествляется с `(0, -v)`. Нормали на стыке меняют знак: непрерывная ориентация на ленте Мёбиуса невозможна. Для корректного освещения используется двусторонний материал и аналитические нормали. Конечный ряд вершин точно копирует начальный в обратном порядке, поэтому на стыке нет щели. Рендер-сетка имеет 256 × 32 ячеек; гладкая математическая поверхность отображается треугольным приближением.

`npm test` проверяет стык, нормали, невырожденность треугольников, единственность края, характеристику Эйлера и неориентируемость после отождествления вершин стыка. `npm run check` проверяет синтаксис. Зависимости для проверок устанавливать не нужно.

Справочные материалы: [параметризация Wolfram MathWorld](https://mathworld.wolfram.com/MoebiusStrip.html), [Three.js](https://threejs.org/).

## Технологии и лицензии

HTML, CSS, JavaScript, WebGL / Three.js r160. Внешняя библиотека и управление камерой включены локально в `assets/vendor`. В TrackballControls изменён путь импорта и очищается инерция при возврате к исходному ракурсу. Three.js распространяется по [MIT](assets/vendor/THREE-LICENSE.txt).
